# DEDSEC Demo Terminal

Демонстрационное приложение в стиле DEDSEC: Dashboard, Recon, System, Alerts, Payloads, Settings и терминал-эмулятор. Интерфейс адаптирован под телефон и компьютер, работает без внешних библиотек и без доступа в интернет.

## Самый быстрый запуск — без Gradle

1. Распакуй архив.
2. Открой `web/index.html` в браузере — приложение запустится сразу, без установки зависимостей и сборки.
3. Для Android 7.0+ (API 24+) см. раздел «APK без локальной сборки» ниже.

При открытии HTML напрямую часть PWA-возможностей (установка с экрана «Установить приложение» и Service Worker) зависит от браузера и origin. Основной интерфейс работает и как локальный HTML-файл.

## APK без локальной сборки Gradle

В папке `.github/workflows` находится workflow для облачной сборки APK. Локально устанавливать Android Studio или запускать Gradle не требуется.

1. Создай новый пустой репозиторий GitHub.
2. Загрузи в него содержимое этого проекта вместе с папками `.github`, `android` и `web`.
3. Открой вкладку **Actions** и выбери **Build DEDSEC Demo APK**. После первого push workflow также запускается автоматически.
4. Открой завершённый запуск workflow и скачай artifact **`dedsec-demo-debug-apk`**.
5. Распакуй artifact и установи `app-debug.apk` на Android. Если система спросит, разреши установку приложений для используемого файлового менеджера/браузера.

APK — debug-сборка для демонстрации и ручной установки, не релиз для Google Play. Minimum SDK — **24 (Android 7.0)**. Приложение не требует установленного Gradle на твоём компьютере; GitHub Actions собирает APK в облаке.

## Что работает

- **Overview:** дашборд, часы, состояние сети, батарея и память, когда эти данные доступны.
- **Terminal:** безопасный эмулятор с командами `help`, `status`, `sysinfo`, `network`, `recon --demo`, `alerts`, `payloads`, `date`, `whoami`, `ping demo`, `clear`.
- **Recon:** анимированный радар и вымышленный набор точек доступа.
- **System:** read-only сведения Android (модель, версия ОС/API, батарея, доступная/общая RAM, свободное/общее место и тип сети). CPU-график синтетический.
- **Alerts:** локальные демонстрационные события, фильтры, подтверждение и удаление.
- **Payloads:** только визуальные симуляции — никаких эксплойтов или действий над устройством.
- **Settings:** scanlines, анимации, компактный режим, цвет акцента и сброс локального состояния.

## Безопасность и ограничения

- Приложение не сканирует Wi-Fi, не перехватывает трафик и не отправляет сетевые запросы.
- Терминал не запускает команды Android/Linux и не предоставляет системную оболочку.
- Все recon-результаты и payload-сценарии — демонстрационные данные.
- Реальные read-only показатели Android доступны только в Android-оболочке; при запуске в браузере некоторые значения заменяются на `DEMO`/`UNAVAILABLE`.
- Приложение не использует интернет-разрешение; доступ к состоянию подключения нужен только для отображения типа сети.

## Структура

- `web/` — автономная браузерная версия.
- `android/` — Android WebView-оболочка, `minSdk 24`.
- `.github/workflows/build-apk.yml` — облачная сборка APK через GitHub Actions.
